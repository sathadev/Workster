# 🧾 WorkSter - HR Management System

ระบบบริหารจัดการบุคลากร (HR Management System) 
พัฒนาโดยใช้ **Node.js (Express)**, **React.js**, และ **MySQL**  
ออกแบบมาเพื่อช่วยให้ฝ่ายบุคคล (HR) สามารถบริหารข้อมูลพนักงาน การลา การมาสาย การจ่ายเงินเดือน  
รวมถึงจัดการประกาศรับสมัครงาน และการคัดเลือกผู้สมัครได้อย่างครบวงจร


---

## 🧩 ระบบหลัก (Main Features)

### 👩‍💼 Core HR
- จัดการข้อมูลพนักงาน (Employee Management)
- ระบบบันทึกเวลาเข้า-ออกงาน (Attendance)
- ระบบลางานและอนุมัติการลา (Leave Management)
- ระบบประเมินผลพนักงาน (Evaluation)
- ระบบเงินเดือน (Salary & Deduction)
- ระบบข้อมูลบริษัทและนโยบาย (About / Settings)

### 💼 Recruitment
- สร้างและเผยแพร่ประกาศรับสมัครงาน (Job Posting)
- ระบบรับใบสมัครออนไลน์ (Job Applications)
- จัดการการสัมภาษณ์และผลการคัดเลือก (Interview & Decision)
- ระบบสมัครสมาชิกบริษัทใหม่ (Company Registration)

### 🧑‍💻 Authentication & Roles
- Super Admin (จัดการบริษัททั้งหมด)
- Company Admin / HR (จัดการพนักงานในบริษัท)
- Employee (เข้าดูข้อมูลตนเอง)
- Public Users (สมัครงาน)
